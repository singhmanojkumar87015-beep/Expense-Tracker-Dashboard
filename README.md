# Expense Tracker Dashboard 📊

An interactive Excel dashboard designed to track, analyze, and visualize personal expenses efficiently.

## 📌 Project Overview

This project provides a simple and user-friendly way to monitor expenses by category and gain insights into spending patterns.

## ✨ Features

- Expense tracking and categorization
- Interactive dashboard
- Expense-by-category visualization
- Pie chart for spending analysis
- Clean and easy-to-understand layout
- Excel-based data analysis

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Data Analysis
- Data Visualization
- Pivot Tables & Charts
- Dashboard Design

## 📊 Dashboard

The dashboard provides a visual summary of expenses across different categories such as Food, Travel, and Shopping.

## 🎯 Objective

The goal of this project is to demonstrate practical Excel skills and create a useful dashboard for personal expense management.
